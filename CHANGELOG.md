- F21 Phase 6 (pull; see QUEUER_REMOTE_PLAN.md). New `remote_pull.py`: `qur pull HOST:ID [--to DIR] [--exclude PATTERN ...] [--no-default-excludes] [--max-mb N] [--extract] [--force]` runs `qur remote pack` on the worker and streams to `<pull_dir>/<folder>.tar.gz.part`; the file (gzip CRC and a full `tarfile` listing) is checked before it gets its final name, so an interrupted or corrupt transfer leaves only a `.part`. An existing tarball is never replaced without `--force`; `--extract` unpacks next to it with the safe-extraction rules of `remote receive`. `qur pull HOST:ID --file REL [--to PATH]` fetches one file (5 MB unless `--max-mb`). Defaults come from `hosts.json` (`pull_dir`, `pull_exclude`). Auto-pull: `qur run --pull` / `qur rerun --pull` make the watcher pull when the job ends `done` or `failed` (not cancelled or skipped), in a separate task (one pull per host at a time, never blocking the poll loop), and send "pulled to PATH (SIZE)"; a failed pull is reported and retried at the next poll, 3 tries in all. A rerun reuses its folder, so an automatic pull is named `<folder>-<job id>.tar.gz` instead of colliding.

Strict FIFO: a delayed job at the head of its channel holds the channel until its time; the daemon sleeps exactly until `not_before` (capped at the 30 s recheck, so a clock jump or suspend cannot delay it by more than that). With dependencies both must be met; a failed dependency still skips it at once; a paused channel waits for `qur resume`. `qur list` has a "Starts at" column, `qur show` and Telegram Details/List show the start time. Applies to every job of a sweep. `--delay`/`--at` exclude each other and `--now`. Requeued and retried jobs are not delayed. Timeout counts run time only.
- Telegram: button presses that piled up while the daemon was off (more than 5 minutes) are dropped, not run late; a double tap on Requeue requeues once.
- `qur logs`: streams big logs instead of loading them; new `-n/--lines`.
- Idle workers wake on every real change and re-check only every 30 s (was every second).
- Socket: at most 32 connections at once.
- Telegram calls ignore proxy environment variables (token is in the URL); `QUEUER_USE_PROXY=1` opts back in.
- `install.sh`: uv is installed from a pinned release and SHA-256, not an unpinned installer script.
- CI: GitHub Actions runs the tests and a dependency audit.
- `--before/--after` help says clearly they set queue position only.
